# P1 Tree View for the Pages/Posts List – Implementation Plan

**Goal:** On the WordPress Pages/Posts screen (`edit.php`), each original becomes a group. Its translations appear directly below it, connected by directory-tree-style lines, with an expand/collapse button. The Language column appears immediately after Title, and pagination counts groups. This also includes consolidating SVG icons into a sprite (P2 ruling R5).

**Architecture:**
- **Query:** in "tree mode", the main `edit.php` query retrieves only *originals* (adding conditions through `posts_where`/`posts_search`), preserving WordPress pagination and the parent/child page hierarchy. This also works when WordPress queries pages using `fields => id=>parent`.
- **Rendering translation rows:** translation rows are rendered by `WP_Posts_List_Table::single_row()` itself (preserving Quick Edit, checkboxes, and bulk actions). The rows are printed into `<template>` elements in the navigation area below the table (`manage_posts_extra_tablenav`, `bottom`).
- **Inserting rows into the table:** `assets/tree.js` moves these rows directly after the original's row, then draws connecting lines and expand/collapse buttons. With JS disabled, the list contains only originals, but progress labels and the Language column still provide access to each translation.
- **Icon sprite:** `Lingolane_UI::icon()` switches to `<use href="#lingolane-i-…">`, and all icon artwork is printed once in `admin_footer`.

**Tech Stack:** PHP 7.4+ (WordPress ≥ 6.2), vanilla JS (no build step), plain CSS using P2 tokens, PHPUnit 9.6 + wp-phpunit.

**Spec:** `docs/specs/2026-10-22-ux-translation-design.md`: section 4 P1; sections 2–3 (prohibitions, constraints); section 6 (post-review decisions). Builds on P2: `docs/plans/2026-10-22-p2-design-system.md`.

## Global Constraints

- WP ≥ 6.2, PHP ≥ 7.4; GPL-2.0-or-later; no external resource loading, no CDN, no external fonts.
- Do not slow down visitors' frontend experience. All code here runs only in the admin area, on `edit.php` for translatable post types (`Lingolane_Query::post_types()`).
- Do not affect other WordPress screens. New CSS selectors may start only with the approved roots, plus the new `body.lingolane-tree` root (Task 2). Extend the P2 scoping test accordingly; do not loosen it arbitrarily.
- All existing WordPress list features must remain functional: Quick Edit, bulk actions (`post[]` checkboxes), column sorting, search, pagination, status views (All/Draft/Trash), and the `lingolane_lang` filter.
- "Shared" posts (`Lingolane_Shared`) and posts without an assigned language remain ordinary rows, without a tree. Shared post types do not enable tree mode.
- Preserve WordPress parent/child page relationships. The tree connects only originals to translations and does not change any post's `post_parent`, including in-memory objects passed to the list table.
- Write UI strings in English, wrap them in translation functions, and use the `lingolane` text domain; update `.pot` and `lingolane-vi.po/.mo`.
- All new selectors use logical properties (`inset-inline-*`, `border-inline-*`, `padding-inline-*`) to support right-to-left languages. Use only `var(--lingolane-dur)`/`var(--lingolane-ease)` for motion.
- Plugin Check: 0 errors; phpcs: 0 errors, no more than the baseline of 26 warnings. Test baseline: 80 passing tests (PHP 8.2 and 7.4). The test command is provided during execution (copy at `/tmp/lingolane-run/phpunit.sh` for the worktree).
- Performance: retrieve group data for all originals on a list page with a constant number of queries (≤ 3 SQL queries, regardless of row count).

## Review Focus

1. **Quick Edit and bulk actions on relocated translation rows.** The `post[]` checkbox and `#inline_{id}` block must remain inside the row. After saving Quick Edit, the row must stay below its original and retain its connecting lines. Markup tests in Task 5, hands-on verification in Task 7.
2. **JS disabled:** all originals remain visible, and progress labels and the Language column provide access to each translation. No row becomes inaccessible. Tests in Task 5.
3. **Orphan translations** (whose originals have been deleted or trashed) must still appear as ordinary rows. Tests in Task 4.
4. **Large sites:** retrieving groups for 20 originals takes ≤ 3 queries. Count `$wpdb->num_queries` in the Task 3 test.
5. **Filtering by a single language, the Trash view, and shared post types:** return the existing flat list without hiding any translations. Tests in Task 4.
